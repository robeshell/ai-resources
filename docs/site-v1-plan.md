# AI 资料站 V1 规划

## 产品定位

帮助用户从“我要完成什么”出发，找到值得使用的 AI 产品、Skill 和开源项目。

模型目录、价格、评测和排行继续由独立的 LLM Model Comparison 站点负责。本项目只提供清晰外链和上下文关联，不复制模型数据。

## 公开信息架构

1. 首页：第一层按使用场景切换，第二层按 AI 产品、Skills、开源项目和模型切换，不设置宣传首屏和说明区块。
2. 场景分类：写作办公、编程开发、图像设计、视频音频、搜索研究、自动化。
3. 资源类型：AI 产品、Skills、开源项目、模型。模型暂时链接到独立模型站。
4. 资源详情：推荐结论、简介、适用平台、价格信息、相关资源和模型入口。
5. 场景方案不进入 V1 首页，避免增加与资源发现无关的编辑内容。

## 数据边界

- `data/tools.json`：可直接使用的商业或公共 AI 产品。
- `data/resources.json`：Skills、MCP、插件和 GitHub 开源项目。
- `data/scenarios.json`：场景标题、预期结果、说明和关联资源。
- `data/site.json`：站点更新时间和外部模型站地址。

公开页面继续使用静态导出，不引入数据库和用户账号。

## 内部收录助手（本地 Curator）

内部工具不属于公开站点。约定见 `docs/curator-plan.md`。

当前是本地管理台 `/curator/`，服务只监听 `127.0.0.1:4317`：总览、资源库、收录、模型清单、场景方案、站点设置。收录仍走本机 Codex / Claude Code。确认后写 JSON，再用「生成预览」看公开站。

后续再考虑从确认结果开 PR，而不是继续直接写仓库。稳定处理 30–50 条真实链接后，再判断是否抽成通用开源项目。

## 暂不进入 V1

- 资讯流和每日新闻
- 社区、评论与用户账号
- X 动态聚合
- 自动发布未经审核的 AI 内容
- 把模型排行数据复制进本站
